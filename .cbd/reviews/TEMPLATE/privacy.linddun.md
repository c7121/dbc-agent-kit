# Privacy threat model — LINDDUN (optional)

Only apply if the system processes personal data or makes individuals linkable/identifiable.

## Categories
LINDDUN:
- Linkability
- Identifiability
- Non-repudiation
- Detectability
- Disclosure of information
- Unawareness
- Non-compliance

## Threats
Each threat:
- id: LINDDUN-001
- DFD element
- category
- description
- personal data involved
- privacy harm
- mitigation(s)
- verification (test/process/control)
- status: open | mitigated | accepted-risk | deferred
